How to Install RecallLC

Compatible with Google Chrome, Brave, Microsoft Edge, and Arc Browser (Chromium 116+).

Official Chrome Web Store Installation

Install directly in 1-click with automatic updates enabled:

👉 Add to Chrome (Chrome Web Store) ↗

Alternatively, you can build and load RecallLC as an unpacked developer extension directly through GitHub:

⚡ Quick Checklist

  • Browser: Any modern Chromium browser (Chrome 116+, Brave, Arc, Edge).
  • Required folder: You must select the dist folder when loading the extension.
  • Time required: ~60 seconds.

Step-by-Step Installation Instructions

Step 1: Obtain the Extension Code

You have two simple options to get the extension files on your machine:

Option A: Direct ZIP Download (No Git required)

  1. Open the official repository: https://github.com/PranavSharma1008/RecalLc.
  2. Click the green Code button and select Download ZIP (or click here for direct download).
  3. Extract the downloaded .zip file to a folder on your computer (e.g. your Documents or Projects folder).

Option B: Git Clone (Recommended for easy updates)

git clone https://github.com/PranavSharma1008/RecalLc.git

Step 2: Locate the dist Folder

The production extension assets are compiled inside the dist directory within the project folder. Ensure this directory contains manifest.json and the extension assets.

If you cloned the source repository and wish to build it yourself:

cd RecalLc && npm install && npm run build

Step 3: Open Chrome Extensions Manager

Open a new tab in Google Chrome and navigate to the Extensions management page:

chrome://extensions

Step 4: Enable Developer Mode

In the top-right corner of the chrome://extensions page, toggle the switch labeled Developer mode to ON.

Step 5: Load Unpacked Extension

  1. Click the Load unpacked button that appears in the top-left toolbar.
  2. In the file dialog, navigate into the extracted RecalLc folder and select the dist folder.
  3. Click Select or Open.

Important: Do not select the root project folder. Make sure you select the dist subfolder which directly contains manifest.json.

Step 6: Pin & Test

  1. Click the puzzle piece icon (Extensions menu) in the top-right corner of your browser toolbar.
  2. Find RecallLC and click the Pin icon to keep it accessible.
  3. Click the RecallLC icon to verify the popup queue displays correctly.
  4. Navigate to any LeetCode problem (e.g. leetcode.com/problems/two-sum/) to test the in-page reminder and Inline Rocket button!

How to Update RecallLC

Because unpacked extensions do not receive automatic updates from the Chrome Web Store, update manually when a new version is published:

  1. If using Git, run git pull && npm run build in your terminal.
  2. If using ZIP, download and extract the new release archive into the same location.
  3. Open chrome://extensions.
  4. Find the RecallLC card and click the circular Reload icon (⟳).

Note: Your revision schedule, attempts history, and personal notes stored in IndexedDB are fully preserved when you reload the extension.

Troubleshooting & FAQ

"Manifest file is missing or unreadable"

This error occurs if you selected the outer project root folder rather than the dist directory. Re-click Load unpacked and select the dist folder directly.

The in-page reminder doesn't appear on LeetCode

1. Check that you are on an actual problem page (URLs matching https://leetcode.com/problems/*).
2. RecallLC intentionally excludes the problem you currently have open from its reminder.
3. If no problems are due for revision yet, solve a question or click the Inline Rocket button on LeetCode to schedule one!
