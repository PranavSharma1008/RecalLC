How RecallLC Works

No complex setup. Just install the extension and practice on LeetCode as you normally do.

1

Solve a Problem

Open any question on LeetCode. RecallLC silently tracks your verdict or lets you push the problem with the topbar Rocket button.

2

Receive a Spaced Nudge

When you start a new question days later, a compact reminder card displays an older problem due for revision. The active question is excluded.

3

Recall Before Revealing

Open the Recall screen. Review your approach, complexity, and trade-offs before clicking to reveal your past notes.

4

Rate & Reschedule

Rate how easily you recalled the solution (Forgot, Hard, Good, or Easy). RecallLC calculates the next revision date and maintains your streak.

Installation Guide

How to Install RecallLC

RecallLC is distributed directly through GitHub. Follow these step-by-step instructions to load it into Google Chrome in under 60 seconds.

  1. 1

    Clone or Download the Repository

    Download the project repository archive from GitHub or clone it using your terminal:

    git clone https://github.com/PranavSharma1008/RecalLc.git
  2. 2

    Open Chrome Extensions

    In Google Chrome, navigate to the extensions management screen by typing this into your address bar:

    chrome://extensions
  3. 3

    Enable Developer Mode

    Toggle the Developer mode switch located in the top-right corner of the Chrome extensions page.

  4. 4

    Click "Load unpacked" & Select the dist Folder

    Click the Load unpacked button (top-left) and select the dist folder inside the extracted RecallLC directory (or run npm run build first if building from source).

  5. 5

    Pin to Toolbar & Start Revising

    Click the puzzle icon in Chrome and pin RecallLC. Open any problem on leetcode.com to see it in action!

Developer Mode Notice: Unpacked Chrome extensions do not update automatically from the Chrome Web Store. When a new version is released on GitHub, simply pull the latest changes (or re-download the archive) and press the reload (⟳) icon on the RecallLC card in chrome://extensions.

Got Questions?

Frequently Asked Questions

Accurate, transparent answers about RecallLC's architecture, permissions, and distribution.

Why is RecallLC installed via GitHub rather than the Chrome Web Store? +
RecallLC is currently distributed through GitHub so developers can inspect the source code, run unit tests, and load the unpacked extension immediately. Chrome Web Store verification and listing submission are currently in preparation.
Does RecallLC have access to my LeetCode password or cookies? +
No. Absolutely never. RecallLC does not request the cookies, webRequest, or tabs permissions. It never reads, stores, or forwards session credentials. All catalog requests originate from your existing tab context with standard browser security.
Where is my revision schedule and problem data stored? +
All problem logs, attempts, and schedules live entirely on your own device inside the browser's IndexedDB (isolated to the extension origin) and chrome.storage.local. Nothing is sent to any external server because RecallLC operates completely without a cloud backend.
What happens if I dismiss a revision reminder? +
Unlike simplistic reminder tools, RecallLC stores dismissals in a separate dismissedAt field. Dismissing a card merely hides it for the rest of today—it never reschedules your problem. Only explicitly rating your recall (Forgot, Hard, Good, Easy) moves your revision due date.
How do I update RecallLC when a new version is released? +
Because unpacked extensions are loaded from your local disk, simply pull the latest code with git pull (or download the latest ZIP release) and click the reload icon (⟳) on the RecallLC card in chrome://extensions. Your IndexedDB data is fully preserved across reloads.
How can I support development or submit feature requests? +
You can star the project on GitHub, open an issue for feature suggestions, or sponsor the developer directly through GitHub Sponsors.
